# Contribuindo com o ZCARD

Obrigado pelo interesse no projeto.

O ZCARD é um projeto experimental de formato aberto de mídia para jogos.

## Antes de contribuir

Alterações significativas na especificação devem ser discutidas antes da implementação.

Isso é especialmente importante para:

- Estrutura do formato
- Compatibilidade
- Versionamento
- ZCF
- ZEXE
- Hardware
- Protocolos

## Áreas de contribuição

- Especificação
- C++
- Emulação
- Armazenamento
- Sistemas de arquivos
- Hardware
- Sistemas embarcados
- Memória Flash
- Protocolos
- Segurança
- Desenvolvimento de jogos
- Ferramentas
- Documentação

## Pull Requests

Um Pull Request deve explicar:

- O que foi alterado;
- Por que foi alterado;
- Como foi testado;
- Impactos na compatibilidade.

Alterações no formato devem atualizar a documentação correspondente.

## Compatibilidade

A compatibilidade é uma prioridade do projeto.

Evite alterações incompatíveis sem uma justificativa técnica clara.

## Discussões

Propostas arquiteturais devem ser discutidas antes de grandes implementações.

O objetivo é manter a especificação independente de uma implementação específica.
