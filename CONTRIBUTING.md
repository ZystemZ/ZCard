# Contribuindo com o ZCARD

Obrigado pelo interesse no projeto ZCARD.

O ZCARD é um projeto experimental de desenvolvimento de um formato aberto de mídia para jogos.

## Antes de contribuir

Alterações significativas na especificação devem ser discutidas antes de serem implementadas.

Isso é especialmente importante para:

* Estrutura do formato;
* Compatibilidade;
* Versionamento;
* ZCF;
* ZEXE;
* Hardware;
* Protocolos.

## Áreas de contribuição

Contribuições são bem-vindas em:

* Especificação;
* C++;
* Emulação;
* Armazenamento;
* Sistemas de arquivos;
* Hardware;
* Sistemas embarcados;
* Memória Flash;
* Protocolos;
* Segurança;
* Desenvolvimento de jogos;
* Ferramentas;
* Documentação.

## Pull Requests

Pull Requests devem explicar:

* O que foi alterado;
* Por que foi alterado;
* Como foi testado;
* Se existe impacto na compatibilidade.

Alterações no formato devem incluir documentação.

## Compatibilidade

Compatibilidade é uma das prioridades do projeto.

Evite alterações que quebrem versões existentes sem uma justificativa técnica clara.

## Desenvolvimento

O código da implementação de referência utiliza C++.

Consulte o repositório correspondente para instruções específicas de compilação.

## Discussões

Propostas relacionadas à arquitetura do formato devem utilizar Issues ou Discussions antes de grandes implementações.

O objetivo é manter a especificação independente de uma implementação específica.
